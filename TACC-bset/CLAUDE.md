# TAAC 涨点优先级记录

这份记录只保留当前阶段对预测涨点更有帮助的方向，目标是指导后续实验优先级，而不是罗列所有可能改动。

## 当前判断

基于当前代码结构和数据处理方式，最值得优先做的涨点方向是：

1. `#6 Target Attention / DIN`
2. `#3 缺失值差异化处理`
3. `#1 时间分桶按真实分布重画`
4. `#7 时间信息作为 attention bias`
5. `#5 显式交叉特征增强（优先 DCN v2，其次 SENet）`

## 为什么这些更有效

### 1. `#6 Target Attention / DIN`

这是当前最像“直接提升预测能力”的结构改动。

现有 `ui_aware` 更接近“item 感知 user 非序列特征，再结合序列摘要生成 query”，但还不是“当前 item 直接从历史行为里挑相关兴趣”。  
对 CVR 场景来说，DIN 这类“针对当前广告激活历史兴趣”的建模通常更贴任务本质，所以预期收益最高。

当前分支已经实现了这条思路：在原有主干之外新增 `DIN-style target attention residual`，不替换现有 `ui_aware` 路径。

### 2. `#3 缺失值差异化处理`

这是当前数据管道里非常明显的硬伤。

现在 `missing / padding / 真实 0` 都可能被压到同一个语义上，会污染特征表达。  
这类问题往往不像新结构那样“惊艳”，但通常属于低风险稳收益，值得尽快修。

### 3. `#1 时间分桶按真实分布重画`

当前 `time_diff` 已经进了模型，但桶边界是手工设置的。

如果真实分布和手工边界不匹配，就会出现大量空桶或者前几个桶过度拥挤，导致时间 embedding 利用率不高。  
按训练集真实分布重画分桶，通常是性价比很高的数据侧优化。

### 4. `#7 时间信息作为 attention bias`

这个方向本身有价值，但更适合作为 `#6` 的增强项，而不是第一个单独实验。

现在时间信息主要是加到 token embedding 里，还没有真正影响“当前 item 更应该关注哪些更近的历史行为”。  
如果后面把时间差显式做进 target attention 打分，它通常和 DIN 是联动收益。

### 5. `#5 显式交叉特征增强`

这个方向可能涨，但优先级低于前面几项。

当前模型已经叠了不少结构，继续加 DCN v2 / SENet 可能有帮助，但更像中后期精修。  
如果要做，优先考虑 `DCN v2`，再考虑 `SENet`。

## 建议实验顺序

建议优先按下面顺序推进：

1. `#6 DIN` 主实验
2. `#3 缺失值差异化`
3. `#1 时间分桶重画`
4. `#6 + #7` 联合实验
5. `#5 DCN v2 / SENet`

如果实验资源有限，最核心的三组对照是：

1. `baseline`
2. `baseline + DIN`
3. `baseline + DIN + 更合理的时间建模`

## 不建议当前优先做的项

以下方向不是没价值，而是当前阶段不该排在前面：

- `#13 / #14 / #15`
  它们更偏诊断和分析工具，重要，但不直接涨点。
- `#2`
  更偏提效和减少浪费，可能顺带小涨，但通常不是主涨点来源。
- `#4`
  当前默认配置不走 `ns_groups.json`，短期收益不大。
- `#8`
  依赖先看清真实序列长度分布，否则容易做成低收益复杂改动。
- `#9`
  `warmup + cosine` 值得补，但更偏训练稳定性，不是最直接的预测收益来源。
- `#10 / #12`
  当前阶段不建议先碰。

## 一句话结论

当前最值得押注的涨点方向是：`#6 DIN`。  
当前最值得补的数据地基是：`#3 缺失值差异化` 和 `#1 时间分桶重画`。  
当前最适合作为 `DIN` 后续增强的是：`#7 时间 bias`。
